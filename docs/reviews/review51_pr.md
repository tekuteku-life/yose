# PRタイトル

fix(data): 追加・編集・取込・同期の整合性検証と一括保存を統一

## 概要 / 背景 (Background)

複数端末でカテゴリ・明細を更新した際に、存在しない参照先、親子分類の不一致、古い編集画面による上書き、取込・受信の部分保存が生じる問題を修正する。更新経路を監査し、UI・ローカルDB・GASの保存境界で整合性を確認する。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- 型・ID・金額・日時・口座・分類・定期・保険・予算・集計の共通検証を追加し、同じコードをGASへ生成する。通常操作は既存問題の不変保持・修復を許し、新しい問題を拒否する。完全取込は候補全体を厳格検証する。
- 変更候補の検証・事前暗号化後に原本と認証鍵を比較し、明細・マスタ・snapshotを一括保存する。完全取込では確認済みplanも保護する。GASの多ファイル変更は永続journalで確定・復旧する。
- マスタ・明細・削除・一括編集・精算で並行更新を保護する。同期はマスタを先に送り、受信・ACK・snapshotを原子的に適用する。
- 実態中項目の明示null、未入力金額と明示0、アーカイブ履歴を保持する。定期・カード精算は二重生成を防ぎ、カード精算の請求周期と確定額集計を修正する。
- テーマ・折畳みの保存順を保証し、ローカル保存完了後は通信待機中も再編集できる。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

- 新規: `js/logic/data_integrity.js`、GAS生成・一致検査、全境界の単体・結合・UI回帰、監査・レビュー記録である。
- 変更: `js/db/*`、`js/sync.js`、`gas/Code.gs`、入力・編集・マスタ・設定UI、生成・集計、仕様書・UI監査表、PWA1.11.1である。
- 削除: 共通一括保存への統合で未使用になった旧条件付き保存3メソッドである。
