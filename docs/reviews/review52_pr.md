# PRタイトル

feat(ui): メンテナンス更新と費目推移・期間別フィルターを改善

## 概要 / 背景 (Background)

アーカイブ設定のメンテナンスで更新結果が分かりにくく、未参照設定も候補に出る問題を修正する。収支の費目カードへ費目ごとの時系列を追加し、期間内に明細があるアーカイブ設定でも明細を絞り込めるようにする。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- メンテナンスは参照明細が1件以上ある設定だけを件数付きで提示し、選択元の一覧を最新DBから更新する。更新状態・選択保持・後着旧応答・移行中操作・再取得失敗を扱う。
- 明細フィルターは期間元明細の計上/実態分類と振替元/先から候補を算出する。年/月は計上月、日は取引日を使い、有効設定と期間内参照済みアーカイブ設定を表示する。
- 費目別支出推移を日/月/年に対応させ、分類軸・予定表示を反映する。月次snapshotと取得済み明細を重ねて数えず、日別へ月集計を推測配分しない。取得済み範囲を明示する。
- Chart.js不可時の安全な表表示、空状態、テーマ切替、古い描画の拒否に対応する。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

- 新規: `js/logic/category_trend.js`、費目推移unit/UI、アーカイブfilter UI、レビュー記録である。
- 変更: メンテナンス集計/UI、収支summary・chart・明細filter、HTML、設計・監査表、PWA1.12.0である。
- 既存のドーナツ・内訳・ドリルダウンと新規登録のアーカイブ選択禁止を維持する。
