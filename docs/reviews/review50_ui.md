# Review 50: セクション開閉と編集分類の統合

## 先行設計

対象は既存の開閉機能が存在する収支・予算・資産および設定のカードである。タイトルバーの文字・余白クリックを既存の開閉処理に接続する。タイトル内のbutton、a、input、select、textarea、label、summary、contenteditable、role付き操作要素からのイベントは除外し、右端ボタンは既存の独立操作を維持する。タイトルにキーボード操作を追加する場合は、既存の子操作要素を含むrole=buttonを作らず、見出し文字をネイティブの開閉buttonとして包み、文字側buttonと右端buttonが同じ状態をaria-expandedで共有する。バー余白はclickのみとし、Enter/Spaceはネイティブbuttonで単一発火する。表示状態は既存collapsed_panesを使用する。

編集分類には新規入力と同じ「実態分類を計上分類と同じにする」チェックを設ける。計上・実態の大項目および中項目の両方が一致する場合のみONで開く。中項目のnullと空文字は未指定として比較する。実態大項目の既存フォールバックは保持し、実態中項目は欠損を勝手に補完しない。振替は分類全体を非表示にし、既存null保存を維持する。

ONへの変更時とON中の計上分類変更時は実態selectのoptionとvalueを計上selectから同期し、アーカイブ・不明IDを維持する。ON中の保存値は計上selectから直接取得する。大項目に伴う非同期中項目更新は既存親IDガードに従い、完了後の現在値から同期する。OFF時は直近の同期値から実態を別編集できる。dirty判定にcheckbox.checkedを含め、未変更の開閉には破棄確認を出さない。

UI変更のみであり、保存スキーマ、暗号化境界、GASおよび通信プロトコルは変更しない。cascade保存にも同じ分類値取得を適用する。

## 先行テスト観点

- タイトル内button、link、select、input、label、contenteditableの操作が開閉されないこと、Enter/Spaceが一度だけ切り替えることを確認する。
- 同分類・空中項目・アーカイブ同分類はON、親だけ違う/子だけ違う分類はOFF、振替は分類非表示で開くことを確認する。
- ON中の親子変更保存、OFFで別分類保存、再ONで追従、チェックのみ変更した場合の戻る破棄確認、未変更close、前払cascade、振替null保存を確認する。

## 390px見出しの潰れに対するPhase 1再入

親担当の最終スマホ目視で、年間予算カードの見出しが試算buttonと開閉buttonに圧迫され、幅20px程度となり一文字ずつ縦に積まれていた。見出しbuttonのflex:1とmin-width:0に対し、親タイトルバーに折り返しがないことが原因である。操作イベントではなくレスポンシブ配置設計の不足としてPhase 1へ戻る。

開閉タイトルバーはflex-wrap:wrapとし、見出しbuttonはflex-basis:12em、min-width:min(100%,12em)を持つ。12emは全角約12文字分であり、見出しを読める語群として表示しつつ、小さいコンテナでは100%以内に収める根拠である。ボタン・フィルタは既存のイベント境界を維持し、収まらない場合は次の行へ自然に回す。JSとDOM構造は変更しない。

先行UIテストでは実390 CSS pxを指定し、年間予算見出しの幅180px以上（標準17.6px文字の約10字分）、高さが3行以内、バーの横はみ出しなしを検証する。390px表示の年間予算見出しは約19全角文字であり、幅180pxあれば2〜3行以内に収まる読みやすさを期待する。試算button・右端buttonが画面内にあり、試算button本来の確認と見出し/右端の単一開閉も確認する。追加後は独立設計・テスト・最終コードレビューを再実行する。

390px配置の先行設計はreview50_auditの独立レビューでPASSとなった。

先行390pxテストはCSS変更前に見出し幅35.69px・高さ211.13px（8行）でFAILとなり、指摘事象を捕捉した。独立テスト観点レビューはPASSである。設計どおりCSSの折り返し・見出しbasis/min-widthのみを修正し、操作JSは変更しない。
