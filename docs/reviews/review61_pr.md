# PRタイトル

feat(ui): データ情報・税控除の表示と明細ページ操作を改善

## 概要 / 背景 (Background)

データ情報と税控除の説明・入力・結果が同じ調子で並び、明細一覧は下側の前後ボタンだけで移動するため、目的の情報やページに到達しづらかった。表示の階層と一覧操作を整理する変更である。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- データ情報は5項目の箇条書きとし、注意書きは余白・区切り線の下に小さく表示する。
- 税控除は項目見出し・入力ラベル・説明・採用額・計算結果を分け、概算上限を強調する。不足項目は独立した注意文、参考集計は表とする。
- 明細の上下に前後ボタンとページ情報、下側に番号選択を設ける。明示的なページ移動後に固定ヘッダーを避けて一覧先頭へ移動する。同期・絞り込みの再描画では移動しない。古い非同期処理は描画世代と操作世代で失効させる。
- 既存の収入・支出・振替フィルターに可視ラベルを付け、他の条件とともに幅に応じた列配置とする。保存・計算式の変更はない。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

index.html、css/style.css、tx_list/insights/furusato_controller、UI試験list_navigationを追加し、passkey_prfの認証後準備待ちを修正・回帰拡充する。R/E/I-3.61、文書索引、監査、review61を更新する。下側だけの旧ページイベント登録処理を削除する。版情報5箇所とlockfileを1.18.0へ同期する。
