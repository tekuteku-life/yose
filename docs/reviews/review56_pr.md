# PRタイトル

feat(app): データ情報・明細一括編集・税と控除の概算・投資推移を追加

## 概要 / 背景 (Background)

登録データの規模、複数明細の共通項目、ふるさと納税の利用額、投資の取得原価と口座評価額を画面で確認・更新できるようにする。[要件3.55〜58](../requirements.md#r-3-55)を追加した。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- 設定へ取得済み明細件数、削除済み件数、取引日範囲、暦月/暦年平均、業務JSONのUTF-8バイト数を表示する。鍵・端末設定・未取得データを含めない。
- 一覧のチェック選択から、全対象に適用できる項目だけを一括編集する。変更項目の明示、ページ跨ぎ、絞込での選択解除、原本比較・最新関連検証・再締め承認・原子保存を行う。
- 「税・控除」タブに給与・社会保険・生命保険・住宅ローン・寄附の設定と計算をまとめ、予算には寄附合計・上限・残額と設定導線を表示する。
- 必要額を任意の費目/内訳へ割り当て、未記録分は年額で入力する。手入力と明細を二重加算せず、取得済み年額は対象集合のSHA確認へ結び付ける。明細編集・同期・完全取込後の部分年を確認済みとして流用しない。
- 寄附年2025〜2027年の給与所得・基礎控除、生命保険の新旧/扶養増額を導出する。住宅残高・取得対価・制度条件から税額控除を求め、申告方式・寄附との競合を区分一次関数で比較する。通知書の所得割額/特例税率による従来方式も保持する。未入力・対応年外・合計溢れは未算出として補完を求める。
- 投資額は保有商品の取得原価とし、口座・日付別の記録を次の記録まで据え置く階段系列で表示する。入出金から原価を推定せず、旧拠出額を転用しない。評価額は預り金込みの口座全体であり、観測と後続入出金の参考値として資産KPIへ一貫適用する。差額を含み損益として扱わない。
- 投資記録と税条件を既存の暗号化・マスタ共有同期・バックアップへ統合する。完全履歴の証拠は全状態の受信と同じ原子batchで端末内へ保存し、バックアップ由来の印を信用しない。
- 保存中のフォームを凍結し、失敗/取消時に復元する。ロック/描画世代/古い保存完了による上書きを防ぐ。
- 1.16.0へ更新し、版情報5箇所・lockfile・PWAキャッシュ対象を同期する。
