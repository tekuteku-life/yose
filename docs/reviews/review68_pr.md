# PRタイトル

feat(sync): Android PWAのバックグラウンド差分同期に対応

## 背景

通常の双方向同期が画面側のJavaScriptで実行されており、別アプリへの切替で画面が凍結すると多段通信の続きが進まなくなる問題があった。

## 変更内容

- インストール済みPWAの通常の差分同期を、キャッシュ用Workerとは別スコープのService Workerへ委譲する。
- Workerは既存の同期エンジン、署名処理、メモリDBを再利用する。鍵と平文本文を永続化せず、処理終了・取消・120秒の期限で鍵参照と復号キャッシュを解放する。
- 画面復帰後の結果反映に元セッションと保存内容の比較を用い、同期中の編集を上書きしない。競合・再月締め確認は画面復帰を待ち、確認前の受信件数を保持する。
- 完全インポートはサーバー基準版の永続化による競合保護を維持するため既存の画面内同期を用いる。
- 1.22.0へ更新し、関連5箇所のバージョン・キャッシュ名を同期する。
- 主要追加ファイルは`js/background_sync_client.js`、`js/background_sync_worker.js`、4層の同期テスト5ファイル、`docs/background_sync.md`である。同期Manager・Coordinator・設計文書・監査表を更新する。GAS実装・暗号形式・データ形式は変更しない。
