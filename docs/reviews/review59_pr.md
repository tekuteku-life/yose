# PRタイトル

feat(analytics): 推移グラフの表示操作と収入内訳・年間目標連動を追加

## 概要 / 背景 (Background)

全期間の折れ線で丸が密集して線を確認できず、突発的な出費で通常額も読み取りにくい状態であった。収入の費目別推移・内訳と描画項目の選択を追加し、年間目標の基準を1つ指定した場合に、現在の取得済み年収から他の目標と進捗を一貫して算出する変更である。

対象はR/E/I-3.59と[詳細設計](../chart_budget_improvements.md)である。基準収入は本人確認済みの「確定＋金額入力済み予定」の取得済み合計であり、年収への引き伸ばしは行わない。

---

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- データ点は保持し、折れ線の丸だけを期間長に応じて最大40点へ間引く。Ctrl＋スクロール/2本指で金額軸を操作し、ボタンで自動範囲へ戻す。描画選択はセッションだけの状態である。
- 支出/収入を切り替え、推移・円グラフ・内訳・明細絞込の種別と分類軸を一致させる。月次収入内訳をGASにも保存する。旧月の内訳を再構成する際は完全取得の証拠と合計一致を必要とし、不明分を「収入内訳未取得」とする。
- 年間目標に個別指定/貯蓄率/貯蓄額/支出予算を設ける。元入力だけを保存し、派生目標・進捗・推移を共通計算する。算出不能を0円と誤表示しない。基準と元入力は同期/CASでも一組として扱い、組外の競合選択を保持する。
- Chart.js 4.6.1を本番CDNと開発依存で固定し、実ライブラリのUI試験を行う。追加のzoom pluginは導入しない。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

- 新規: `chart_geometry.js`、`chart_viewport.js`、`budget_settings_controller.js`、詳細設計と4層の追加試験。
- 変更: Chart/Summary/Settings/Coordinator/Auth/明細一覧、予算・収入集計、共有validator、BackupMerger、GAS月集計、画面/CSS、キャッシュと版情報、UIドライバ。
- 削除: SettingsController内の旧予算操作・描画を除去し、専用controllerへ統一した。ChartControllerの重複する推移描画を共通化した。
