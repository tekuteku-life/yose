# Review 47 編集操作・モバイル表示改善

## 設計

- メインナビ・入力モード・マスタのタブ欄は折返しとボタンの縮小を禁止し、欄内の横スクロールを許可する。ページ全体の横はみ出しを生じさせない。
- 新規・編集でタグチップと候補選択処理を共通化する。既存の hidden 値と公開メソッドは維持し、候補の pointerdown で blur による途中タグ確定を抑止する。選択時には途中入力を破棄して候補だけを確定する。キーボードでタグ候補へ移動した場合も確定を延期し、候補から外へ移動した場合は途中タグを確定する。通常のフォーカス移動では途中タグを確定する。IME変換中の Enter は確定操作に使わない。
- 編集メモにも同じ候補を提供し、選択値で入力全体を置き換える。タグ・メモ候補とチップはHTMLエスケープする。
- 編集アクションはキャンセルを左、保存を右に配置する。削除は別段に分離する。閉じる・キャンセル・ブラウザの戻るは同じ破棄確認を使う。
- Escapeも同じ閉じる経路とする。電卓が最前面であればEscape・ブラウザの戻るとも電卓だけを閉じる。配置の根拠は [Material dialogs](https://m1.material.io/components/dialogs.html) の主要操作を右へ配置する方針である。
- タブ選択後は選択ボタンをタブ欄内へスクロールする。クリック・キーボード・画面スワイプはいずれも同じ選択ハンドラを通る。
- 編集時の口座・振替先・計上/実態の大項目と中項目は、現在参照中であればアーカイブ済み項目も表示する。アーカイブ済みの親配下や欠落したIDは現在値として表示し、通常の新規選択には追加しない。明示的な中項目の指定なしを維持し、開くだけで既定値へ置き換えない。
- 開いた直後のフォーム値と税メタデータを基準値として保持する。入力・削除・選択・未確定のタグ文字列を含む値が基準値から変わった場合だけ破棄確認する。変更を元に戻した場合は確認不要である。
- ブラウザの戻るでは既存の離脱ガードが編集画面を先に処理し、既存の履歴位置へ forward で復帰する。取消時は編集内容と暗号鍵を保持し、追加履歴を作らない。編集画面を閉じた後の戻るは従来の画面離脱確認となる。
- モーダル共通の開閉監視で body を現在位置に固定し、背面の body 直下要素を inert にする。最前モーダルだけを操作可能とし、電卓等の重ね表示に対応する。最終モーダルが閉じたら元の inert 状態・body style・スクロール位置・フォーカスを復元する。モーダル内の overscroll は背面へ伝播しない。認証画面が表示された場合はすべてのモーダルを閉じ、inert とスクロール固定を解除する。BFCache復帰・明示ロックの双方で認証画面を操作できる状態にする。

- マスタ再描画は有効な入力選択を保持し、入力中にリモート設定が反映されても口座・振替先・ポイント・計上/実態の大中項目を先頭へ戻さない。子選択の明示空値も保持する。無効化された選択だけ既定値へ移す。非同期の子選択再描画は親IDを再確認し、既に別親へ移った場合に旧親の子を描画しない。

## 先行テスト観点

1. 320px画面でタブは同じ行、タブ欄のみ横スクロール可能であり、末尾タブを操作できる。
2. 編集タグをチップで読取・追加・削除・重複抑止し、新規入力のタグ状態から分離して保存する。
3. 新規・編集の途中タグから実ポインタで候補を選択し、途中タグを保存しない。メモ候補は入力全体を置き換える。HTMLを含む候補もテキスト表示する。
4. 保存が右、削除が別段である。保存・削除・閉じる後は背面操作を復元する。
5. 未変更の戻るは確認なしに編集のみを閉じる。変更時の戻る・閉じる・キャンセルの取消は入力と履歴長を保持し、承認時は編集だけを閉じる。
6. スクロール端でも背面が動かず、背面の入力が inert であり、電卓は操作可能である。閉じた後はスクロール位置とフォーカスを復元する。

## レビューと検証

- 独立レビュワーは `/root/independent_review` である。設計・先行テストを承認後に実装し、指摘のたびに影響する設計・テストへ戻った。
- 初回先行UIは元実装で10件すべて失敗し、未対応の要望を捕捉した。
- 追加指摘では候補のキーボード選択、認証ロック時の inert、電卓表示中の戻るを先行5件で失敗させた。実装後には認証ロックで `classList.remove` の無条件呼出が監視を再発火する不具合を捕捉し、状態が変わる場合だけ変更するよう修正した。
- 欠落親・子配列欠落時の中項目ID保持を2件で失敗させてから修正した。計上・実態の双方についてメモだけの保存で参照を維持する。
- 遅延したマスタ取得の完了後に非先頭の入力選択が失われる同期側UI、および親費目の変更後に遅れて旧親の中項目を描画する編集側UIを先行失敗させてから修正した。
- 入力モードタブも非改行と横スクロールへ横展開し、モバイルUIの追加観点を先行失敗させてから修正した。
- CDPの既存 `key()` は候補ボタンのネイティブEnter起動に必要なvirtual key codeを送っていなかったため、キーボード候補テストは実際のEnterコードと改行文字を送信する形へ是正した。候補Tab移動の二重入力検知は維持している。
