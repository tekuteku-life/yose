# PRタイトル

fix(security): GAS認証の公開鍵登録・再送防止・署名検証を是正

## 概要 / 背景 (Background)

公開鍵が未設定のGASで第三者が初回登録でき、キャッシュ障害時には同じ署名要求を再実行できた。また、署名済みの非数値時刻と恒等点の公開鍵・署名を受理する問題を再現した。所有者による事前設定、永続的な再送拒否、厳格な時刻・鍵検証へ変更する。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- 公開APIの初回鍵登録を拒否する。設定UIとSyncManagerの登録処理を削除し、公開鍵コピーとGAS管理画面への登録手順を提供する。コピー完了後にだけ成功を通知し、失敗/機能不在は手動コピーへ案内する。
- 正の安全な整数の時刻、±5分の有効窓、鍵・署名の正規Base64を要求する。Ed25519は点の正規復号・素数位数部分群・非恒等公開鍵と既存の署名等式を検証する。
- 署名検証後にScriptLockを取得し、時刻と登録鍵を再確認する。署名対象のSHA-512をキーとするScriptPropertiesの独立記録で再送を拒否する。未来時刻の要求も有効期限まで保持し、満杯・保存失敗・読取不整合では業務処理を実行しない。
- 認証記録は業務データの取得・バックアップ・完全置換と分離する。認証記録の確定後にだけ業務ジャーナルを復旧する。業務失敗後の再試行は新しい時刻で署名し、業務IDと完全取込receiptの冪等性は維持する。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

GAS、SyncManager、設定UI/HTML、GASモックと既存認証試験を変更する。認証単体・署名付き月締め/完全取込システム試験、管理登録手順/コピーの実UI試験を追加する。全体試験で見つかったCDPのpipe障害伝播とchild close待機を補強し、既存パスキー試験の実初期化完了待ちを修正する。R/E/I-4.9、専用設計、監査と索引、READMEとsetup:gasの配備手順を更新する。版情報5箇所とlockfileを1.18.1へ同期する。

## 配備時の必須条件

本件はローカル修正とコミットまでであり、本番GASへは未配備である。初回更新は、別URLを含む旧版の全公開停止、旧版の全実行終了の確認、その時刻から10分超の待機を行った後に新版を公開する。既存の正しいUSER_PUBLIC_KEYSは維持し、未設定なら所有者が公開前に登録する。URL変更時はPWAの接続先も更新し、旧要求拒否と新しい署名付き同期を確認する。AUTH_REPLAY_記録を稼働中に削除しない。手順の正本は[認証是正設計](../gas_auth_hardening.md)である。
