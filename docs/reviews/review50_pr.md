# PRタイトル

feat(ui): セクション操作・編集分類の共通化と完全インポートを追加

## 概要 / 背景 (Background)

カード右端だけの開閉と、同じ分類を二重表示する編集画面を改善する。手編集JSONが既存優先・更新日時比較で一部しか取り込まれない問題に対し、従来の差分マージに加え、対象種別を完全に置き換える方式を追加する。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- タイトル文字・余白で開閉でき、内包するボタンや選択欄の操作、キーボード、保存済み開閉状態を維持する。
- 編集で計上・実態の親子分類が一致する場合は共通化チェックをONにし、実態欄を畳む。独立編集・一括編集・変更破棄確認も維持する。
- 完全取込は全5種別に対応し、置換・削除・次回サーバー反映の対象を示して「完全インポート」の正確な入力を求める。全検証と暗号化後、原本比較付きの単一IDBトランザクションでデータと送信待ちを保存する。
- サーバーは署名・版比較・復旧journal・再送receiptで完全置換を処理する。省略明細の削除は他端末へ伝播し、送信中の手元編集はACKで保持する。版競合の再承認、修正ファイルによる保留のやり直しにも明示確認を要求する。

### 2. 対象ファイル一覧 (Modified / Added / Deleted Files)

- 新規: 完全取込の検証・確認UI、単体結合/システム/実ブラウザ回帰テスト、レビュー記録である。
- 変更: 編集・セクション操作、DB/同期/GAS、設定・同期表示、仕様書とPWA1.11.0である。
- 既存の差分取込、通常差分同期、認証鍵・接続先の保持を維持する。
