# PRタイトル

feat(app): パスキー解除・明細日本語化・既存立替回収のひも付けを改善

## 概要 / 背景 (Background)

パスキー認証後にもPIN入力が必要であり、収支明細に英語の仕訳種別が表示されていた。また、既に手入力した回収を元立替へ関連付けられず、未回収候補に残っていた。要件3.49として認証・表示・立替回収の操作を改善する。

2026-10-24のユーザー指定により、本件は要望3点と検証中の関連是正を含む今回の機能差分で区切る。全原本のカバレッジ改善と未変更領域の監査候補は別件とし、[レビュー記録の後続項目](review55.md#既存領域の追加監査候補)へ引き継ぐ。

## 変更内容 (Changes)

### 1. 設計上の変更・判断 (Design Decisions)

- PRF対応パスキーでDMK/署名鍵の暗号ラップを復号し、PIN入力を省略する。PINの復旧経路を維持し、旧/非対応登録は設定で対応パスキーを再登録する。credentialごとの利用者IDによって再登録失敗時の旧パスキー置換を防ぐ。
- 収支一覧と最近の入力に「収入」「支出」「振替」を表示し、保存値は維持する。
- 元立替・既存回収の両編集画面から同額全額の1対1関連付けと解除を行う。回収側の `advance_source_id` を正本とし、新規明細を重複作成しない。収入として入力済みの回収は明示確認によって回収振替へ変換する。
- 原本比較・原子保存・共有整合検査を適用し、過去月と未締め月を単一の承認付き差分バッチで同期する。GASの旧単件APIは共通バッチ処理へ統合する。
- 保存/一覧更新/認証世代の競合を保護し、保存後の一覧更新失敗を保存失敗と区別する。全体UIで発見したGAS URLの入力上書きも、入力世代と未保存状態の管理で防ぐ。
- 全画面認証中は背景をinertにしてTab移動を認証内へ制限し、旧PIN解除モーダルと関連する未使用経路を除去する。
- 明細行や削除ボタンの押下中は一覧のDOM置換を保留し、クリック喪失を防ぐ。最近/期間一覧の描画世代と認証取消を適用し、古い結果や削除済み明細を再表示しない。
- 編集終了時に保留中のひも付け開始も取り消し、遅延ダイアログを復活させない。鍵再生成の取消/失敗時に設定側が成功を重複通知する処理を除去する。
- 版を1.13.0へ更新し、5箇所の版情報・lockfile・PWAキャッシュ資産を同期する。
- Node/実ブラウザ/GAS/SWを同じIstanbul位置情報で測る`test:coverage`を追加し、全原本・各97%を機械判定する。原本hash/位置map/不正counter/計測例外と、ページ破棄・履歴復帰による記録欠落を検査する。
